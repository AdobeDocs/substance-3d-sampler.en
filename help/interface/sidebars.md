# Sidebars

Sampler has two sidebars, the **Left sidebar** and **Right sidebar**.

![](../assets/Sidebars.png)

## Left sidebar

From the **Left sidebar** you can:

* **Add and import content**: Import images and select how they should be integrated into your project.
* **Browse 3D Assets**: Access thousands of materials from Substance 3D Assets inside Creative Cloud Desktop.
* Access **Quick actions**: A collection of actions to quickly achieve certain goals. [Learn more about **Quick Actions**](../features-and-workflows/quick-actions.md)**.**
* Quickly access filters.
* Reopen the following panels when they are closed:
  * The **Quick actions panel**.
  * The **Project panel**.
  * The **Assets panel**.
  * The **Channel Settings panel**.

For more information on the filters available from the **Left sidebar**, see to [Tools and Widgets](tools-and-widgets/tools-and-widgets.md).

## Right sidebar

The **Right sidebar** holds the following panels when they are closed:

* The **Layers panel**.
* The **Properties panel**.
* The **Exposed Parameters Panel**.
* The **Physical Size panel**.
* The **Metadata panel**.
* The **Export panel**.

## Add Filters from the Sidebar

The **Left sidebar** provides quick access to filters. Hovering over a filter icon shows the filter name, and clicking a filter will immediately add it to your stack.

You can also right click a filter to see a list of related filters. For example, right click the **Tiling** filter and you can access the **Auto Tiling** and **Make it Tile** filters.

>[!NOTE]
>
> Using the **right-click menu** to add a filter replaces the original filter in the **Sidebar** with the most recently used filter.
>
> For example, in the animation below, the **Equalize filter** is displayed. After right-clicking and adding the **Fold Remover filter**, the **Equalize filter** is replaced in the **Sidebar** by the **Fold Remover filter**.
>
> ![](../assets/quick-filter-replacement.gif)
